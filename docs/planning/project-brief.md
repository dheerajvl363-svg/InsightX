# InsightX — Phase 0 brief

## Known context

- Event: Smart India Hackathon 2026
- Problem statement: 26152
- Theme: Social Media Analytics

## Discovery decisions to make before implementation

1. Which platforms and access methods are permitted for the prototype?
2. Who is the primary user and which decision should InsightX help them make?
3. What metrics matter most: sentiment, reach, engagement, emerging topics, misinformation signals, or another outcome?
4. What dataset can be legally and reliably demonstrated at the hackathon?
5. What is the minimum end-to-end demo: ingest, analyse, explain, and present?
6. What privacy, platform terms, and data-retention limits apply?

## Phase 0 definition of done

- Repository, documentation, and team workflow are in place.
- Every member can clone the repository, create a branch, open a pull request, and review a change.
- The team has chosen a source dataset/API and written down the first architecture decision.
- No credentials or real social-media exports are committed.
